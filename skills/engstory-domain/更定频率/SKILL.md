# 更定频率 — 生成完后更新词汇频率（触发即执行）

**本技能触发时，对用户给的文本立即扫描更定，把结果端给用户。不要询问、不要先介绍命令——拿到文本直接跑，跑完把输出原样呈现。**

## 唯一的动作

用户会提供文本，三种来源，按此顺序取：

1. 用户消息里直接有文本 → 用行内模式：

```powershell
# 在仓库 skills/engstory-domain/ 目录下执行
python "scripts/mark.py" --text "<全文>" --vocab "<词库路径>"
```

2. 文本在某个文件里（用户给了路径，或本会话刚写好的故事文件）→ 用文件模式：

```powershell
python "scripts/mark.py" --file "<路径>" --vocab "<词库路径>"
```

3. 其他情况 → 把文本经管道传入：

```powershell
"<全文>" | python "scripts/mark.py" --vocab "<词库路径>"
```

默认立即执行，不需要额外参数。若这轮有明确的词单要对照，`--words` 必须传入「检索」技能返回的**词条 key**（逗号分隔）：单义词如 `castle`，多义词如 `blue|蓝色,blue|忧伤`。

- 同一个英文有多个目标释义时，文本中至少出现同样次数，才会给每个独立词条各记一次。
- 只传裸英文且存在多个释义时会报错，避免误记到错误意思。

## 端上来的样子（原样呈现即可）

```
命中 8/10：abandon×1、abrupt×2、absorb×1、...
未用到 2 个：access、accident
另外用到词库里的：seek×1、give up×1
```

如果没给 `--words`，就只报"已记录 N 个词"清单。**不需要解释，不需要加工，直接呈现。**

## 它做了什么（自动，无需告知用户细节）

- 更新命中词的 `uses += 1`（同一次调用每个词只记一次，不按出现次数累加）、`texts += 1`、`last_use = 现在`
- 词形归并：`sought`→seek、`accomplished`→accomplish、`**abrupt**ly`→abrupt、`gave up`→give up
- 同一段文本去重：重复标记直接跳过并提示，防止词频虚高

## 边界

- 只更定频率。不检索（那是 **检索** 技能）、不评判写作、不管文件存放。
- 词库默认 `/workspace/vocab.json`，环境变量 `ENGSTORY_VOCAB` 可改。
