# 写入词汇 — 把新词写进词库（触发即执行）

**本技能触发时，立即把用户给的新单词写进词库并初始化计数，把结果端给用户。不要询问、不要先介绍命令。**

## 唯一的动作

用户消息里会给一批新单词。原样传入（逗号分隔，每个词可带释义）：

```powershell
# 在仓库 skills/engstory-domain/ 目录下执行
python "scripts/add.py" --words "abandon 放弃, abrupt 突然的, give up 放弃(短语)" --vocab "<词库路径>"
```

- 词和释义之间用空格、制表符、逗号、" - " 分隔都行。
- 纯词不带释义也行：`--words "abandon, abrupt, give up"`。
- 词可以是短语（`give up`）。
- 如果词很多、在某个文件里（用户给了路径或你说用文件），就用：
  ```powershell
  python "scripts/add.py" --file "<词表文件路径>" --vocab "<词库路径>"
  ```

## 端上来的样子（原样呈现即可）

```
已放入 2 个新词（频次初始为 0，不会频次=1）：abandon、abrupt
已存在，不会频次 +1：give up
```

**不需要解释，不需要加工，直接呈现。**

## 它做了什么（自动）

- 新词放进词库，数据全初始化为 0：检索次数=0、上次检索=无、使用次数=0、篇数=0、上次使用=无；**不会频次初始 = 1**
- **已存在的词（意思相同/相近）→ 不导入，把它的"不会频次" +1**（这是"不会频次"唯一涨的方式，只在导入时生效）
- **多义词拆分**：一个单词带多个意思时（如 `blue 蓝色 忧伤`），每个意思独立成条、独立计数：
  - 意思**不同**（蓝色 vs 忧伤）→ 拆成独立词条 `blue`、`blue|忧伤`，像两个单词一样各有频次
  - 意思**相近**（蓝色 vs 天蓝色）→ 合并进已有词条，"不会频次"+1
  - 判断依据：释义核心字词的重合度
- 词库文件不存在时会自动创建
- 英文大小写自动归一（`Abandon` → `abandon`）

## 边界

- 只写入。不检索（那是 **检索** 技能）、不更定频率（那是 **更定频率** 技能）。
- 词库默认 `/workspace/vocab.json`，环境变量 `ENGSTORY_VOCAB` 可改。
