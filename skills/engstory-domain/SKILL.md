# 英语词汇故事 Agent 领域规则

本模式只有两个长期词库：

1. **范围词汇库**：限制故事中的普通词汇范围，不表示用户已经掌握。
2. **FSRS 学习库**：保存真正要学习的词，负责目标词选择、使用统计和记忆反馈。

## 内部工具

所有确定性操作都通过以下固定工具完成，不要直接调用脚本或手改 JSON：

- `engstory_select_targets`：从 FSRS 学习库选目标词，开启一个学习批次。
- `engstory_prepare_story_vocab`：从范围词汇库生成本轮允许词汇包。
- `engstory_audit_story`：只读审计故事（目标词命中 + 普通词范围）。
- `engstory_commit_story`：审计通过后保存故事、记录使用、进入反馈阶段。
- `engstory_apply_feedback`：应用用户明确报告的“会/不会/勉强/很熟”。
- `engstory_write_learning_words`：写入用户明确确认的新词。

所有工具都必须显式传入 FSRS 学习库绝对路径；`--range` 传入范围词汇库绝对路径。批次状态默认保存在学习库同目录的 `state.json`。

## 完整工作流（严格按顺序）

### 1. 选目标词

调用 `engstory_select_targets`（默认 7 个）。目标词可以不在范围词汇库中。

### 2. 准备故事词汇包

调用 `engstory_prepare_story_vocab`，得到：
- 目标词（必须使用，豁免范围约束）；
- 允许普通词元（范围库 + 内置功能词 + 明确专名）；
- 允许词形。

### 3. 写故事

模型基于背景与词汇包写 180–400 词纯英文故事：目标词必须全部出现且加粗；普通词尽量落在允许集合内。

### 4. 审计

调用 `engstory_audit_story` 检查目标词与普通词范围。失败则重写（最多 2 次），不提交失败稿。

### 5. 提交

审计通过后调用 `engstory_commit_story`：保存故事文件、记录目标词使用、进入 `WAITING_FEEDBACK`。重复提交同一文本会被词频指纹去重。

### 6. 反馈

把本轮目标词和释义列给用户，等待报告“会/不会/勉强/很熟”。没有用户反馈前不得调用 `engstory_apply_feedback`；工具会拒绝在非反馈阶段调用。

### 7. 发现词确认

审计发现的范围外词进入待确认列表。只有用户明确说“把 X 加入学习库”后，才调用 `engstory_write_learning_words`（`source=story-discovery`）；工具会校验词确实在待确认列表。用户主动导入新词用 `source=user`。

## 输出格式（固定模板，模板外不加任何文字）

- 不得输出"流程执行记录"类表格；不得复述工作流步骤；不得显示难度/稳定性数值；不得使用表情符号或庆祝语。

### 呈现故事

审计、提交均静默，只在失败时说话：

```
## 本轮故事（{N} 词）

**{标题}**

{正文}

已入账：目标词 {命中}/{总数}。
```

若附带记录（如词库已存在但故事用到的词形 `stood`），在一行内说清：
```
已入账：目标词 {命中}/{总数}，另记 {补充记录}。
```

### 报词（故事之后立即给出，无额外寒暄）

```
| # | 词条 | 释义 |
|---|---|---|
| 1 | crypt | 地下室 |
...

逐个报：会 / 不会（可选：勉强 / 很熟）。
```

保留精确词条 key（如 `tale|传说`），因为反馈入账需要。

### 反馈结果（一行，禁止逐词列难度）

```
已记录：会 {a} / 不会 {b} / 勉强 {c} / 很熟 {d}。不会的词{时间}复习。
```

全不会时进一步简化：
```
已全部记为不会，{时间}复习。
```

### 发现词确认（一行 + 一句询问）

```
范围外新词：chase（追逐）、bone（骨头）。加入学习库吗？
```

## 数据文件

- 词库、范围库、故事与状态都是用户的持久学习数据，位于 preset 之外，路径由用户指定或环境变量给出。
- 默认状态文件在学习库同目录 `state.json`；默认故事目录为学习库同目录 `stories/`。
